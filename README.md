# 闲鱼游戏查询助手

独立开发的 Chrome / Edge Manifest V3 插件和 Python 本地查询服务。第一阶段仅提供固定话术和本地资源是否收录的查询，不接入 AI、微信通知、订单、支付或网盘链接发送。

- 接待记录按卖家 ID＋买家 ID 保存在扩展本地存储，刷新不重复欢迎；首条有效查询也记为已接待。“怎么买”“怎么查”可再次获取引导。

- 只处理本次启用或配置更新之后的消息；依赖消息绝对时间区分延迟加载的历史记录。启用前的会话登记为历史接待，不补发欢迎语。尚未实现跨会话未读调度，因此不满足完整的 24 小时多会话接待。

## 启动本地服务

需要 Python 3.10 或以上，无第三方 Python 依赖。在本项目根目录执行：

```sh
python3 service/server.py
```

默认查询相邻爬虫项目的正式库 `scrapers/xdgame/data/xdgame.db`，路径相对于服务文件定位，不受启动目录影响。可用 `--db /绝对路径/其他.db` 覆盖。数据库必须是 SQLite，包含 `games.name` 字段。使用只读连接，不修改或迁移资源库。暂不支持 Excel。

服务默认仅监听 `127.0.0.1:18765`。复制终端显示的访问密钥到插件设置；每次重启服务都会产生新密钥。不要分享密钥。插件固定使用默认端口。

## 加载插件

1. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
2. 启用开发者模式，加载已解压的扩展程序，选择本项目 `extension` 目录。
3. 点击插件图标，打开设置，填写密钥并保存。
4. 在“本地查询测试”输入数据库中的游戏名称，确认能返回结果。
5. 打开闲鱼消息页面，按实际 DOM 校准下述字段，保持自动发送关闭。
6. 完成新消息、切换会话、人工草稿等人工验证后，才开启自动发送。

## 页面适配字段

| 字段 | 含义 |
| --- | --- |
| conversation | 唯一的当前会话元素 CSS 选择器 |
| conversationAttribute | 该元素保存稳定会话 ID 的属性名 |
| sellerAttribute | 当前会话元素上的稳定卖家账号 ID 属性名 |
| buyerAttribute | 当前会话元素上的稳定买家 ID 属性名，不能使用昵称 |
| incoming | 当前会话中买家消息的 CSS 选择器，必须排除卖家和系统消息 |
| text | 买家消息元素内部正文的选择器；为空则读取整个元素文本 |
| idAttribute | 消息元素保存稳定消息 ID 的属性名 |
| timeAttribute | 消息绝对时间属性，支持 10 位秒时间戳、13 位毫秒时间戳、带时区的完整 ISO 时间 |
| input | 当前聊天输入框的选择器 |
| send | 当前聊天发送按钮的选择器 |

适配结构无法用 CSS 和属性表示时，应修改 `content.js` 中的适配函数，不要使用昵称作为会话 ID。尚未获取真实页面结构，未预填未经验证的选择器。

## 回复规则

首次收到新买家的普通消息时发送完整购买及查询引导。仅打开私聊窗口不触发。首条消息是有效查询则直接查询，不叠加欢迎语；后续普通聊天不自动回复。内置“怎么买”“怎么查”按整句精确匹配，始终可以重新获取引导，其他固定话术可在设置中配置。旧设置中的这两个内置关键词自动迁移为完整引导。

查询支持 `查游戏 游戏名称`、`查游戏：游戏名称` 或英文冒号，名称为 1～100 字符且不跨行。无名称或超长时提示正确格式，每条消息最多一个回复。

引导内容：

> 您好，欢迎咨询！
>
> 请先查询您需要的游戏，发送：
>
> 查游戏 游戏名称
>
> 例如：查游戏 黑神话：悟空
>
> 每次查询一款，建议填写完整中文名或英文名。
>
> 查询到资源后，请等待卖家确认版本及可用情况，再下单付款；付款后由卖家提供资源链接。

数据库先精确匹配（英文忽略大小写），没有结果时再按名称包含匹配。返回唯一结果、多个候选或未查到。只返回名称，不读取网盘链接列。已收录不代表资源可下载，不检查链接有效性。

本地服务异常时只记录插件状态，不自动回复“未收录”。发送失败不自动重试，需人工处理。后台先持久化接待占用，再发送；草稿冲突等记为未发送，点击发送记为已尝试而不是已送达，意外中断可能留下处理中状态。可以在设置中查看接待记录。页面重启保留接待记录，但不补处理离线消息；卸载或清除扩展存储会丢失记录。

预览只维护当前页面的预览记录，不记录真实发送成功；历史会话的接待标记仍可写入本地。初期只开一个接待标签页。接待占用经过后台串行处理，但不代表已实现跨标签页聊天调度和完整消息队列。电脑时钟须准确，时间无法读取或晚于本机时暂停处理。
