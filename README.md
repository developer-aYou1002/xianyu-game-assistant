# 闲鱼游戏查询助手

独立开发的 Chrome / Edge Manifest V3 插件和 Python 本地查询服务。第一阶段仅提供固定话术和本地资源是否收录的查询，不接入 AI、微信通知、订单、支付或网盘链接发送。

## 当前完成程度

- 已实现设置页面、本地接口、只读 SQLite 查询、固定话术和结果模板。
- 已实现可配置的当前会话监听、预览模式、内存消息去重、切换会话检查和人工草稿保护。
- **尚未针对真实闲鱼页面完成 DOM 适配和账号联调，不能直接安装后开启无人值守。** 默认关闭监听及自动发送，选择器留空，避免猜测页面结构导致误发。
- 只处理建立基线之后出现的新消息；切换聊天时已有消息视作历史消息，不补回。尚未实现跨会话未读调度，因此不满足完整的 24 小时多会话接待。
- 当前发送器支持 input/textarea；如实际页面采用富文本编辑器，需要增加适配。点击发送不代表已经送达，尚未实现送达确认。

## 启动本地服务

需要 Python 3.10 或以上，无第三方 Python 依赖。在本项目根目录执行：

```sh
python3 service/server.py --db ../scrapers/xdgame/data/xdgame.db
```

请按实际位置修改路径。数据库必须是 SQLite，包含 `games.name` 字段，与现有 xdgame 爬虫结构兼容。使用只读连接，不修改或迁移资源库。暂不支持 Excel。

服务默认仅监听 `127.0.0.1:18765`。复制终端显示的访问密钥到插件设置；每次重启服务都会产生新密钥。不要分享密钥。插件固定使用默认端口。

## 加载插件

1. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
2. 启用开发者模式，加载已解压的扩展程序，选择本项目 `extension` 目录。
3. 点击插件图标，打开设置，填写密钥并保存。
4. 在“本地查询测试”输入数据库中的游戏名称，确认能返回结果。
5. 打开闲鱼消息页面，按实际 DOM 校准下述字段，保持自动发送关闭。
6. 完成新消息、切换会话、人工草稿等人工验证后，才开启自动发送。

## 页面适配字段

| 字段 | 含义 |
| --- | --- |
| conversation | 唯一的当前会话元素 CSS 选择器 |
| conversationAttribute | 该元素保存稳定会话 ID 的属性名 |
| incoming | 当前会话中买家消息的 CSS 选择器，必须排除卖家和系统消息 |
| text | 买家消息元素内部正文的选择器；为空则读取整个元素文本 |
| idAttribute | 消息元素保存稳定消息 ID 的属性名 |
| input | 当前聊天输入框的选择器 |
| send | 当前聊天发送按钮的选择器 |

适配结构无法用 CSS 和属性表示时，应修改 `content.js` 中的适配函数，不要使用昵称作为会话 ID。尚未获取真实页面结构，未预填未经验证的选择器。

## 回复规则

固定话术按整句精确匹配。默认“怎么买”回复“查询游戏请发送：查游戏 游戏名称”。查询支持 `查游戏 游戏名称` 或 `查游戏：游戏名称`。

数据库先精确匹配（英文忽略大小写），没有结果时再按名称包含匹配。返回唯一结果、多个候选或未查到。只返回名称，不读取网盘链接列。已收录不代表资源可下载，不检查链接有效性。

本地服务异常时只记录插件状态，不自动回复“未收录”。发送失败不自动重试，避免重复回复，需人工处理。浏览器重启或页面重新加载后重新建立消息基线。

## 验证

```sh
python3 -m unittest discover -s tests -v
node tests/test_core.js
```

自动验证覆盖查询分支、SQL 输入边界、链接不外泄及话术解析。真实账号联调尚未完成。人工验证应确认：历史消息不回复、卖家消息不触发、买家新消息只处理一次、查询中切换会话不误发、草稿不覆盖、本地服务中断不误报不存在。
